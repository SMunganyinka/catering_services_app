# Catering Services Booking App

The Catering Services Booking App allows users to browse, book, and pay for catering services. Catering providers can manage their services and receive notifications about bookings. This app aims to make catering service booking **easy, fast, and reliable** for both clients and providers in Rwanda.

---

## Features
- **User Registration & Login** for clients and providers  
- **Service Browsing** with search and filters  
- **Booking Management**: create, cancel, and view bookings  
- **Provider Dashboard**: manage services and view bookings  
- **Notifications** via email or SMS  

---

## Technology Stack
- **Frontend:** React, Typescipt and tailwind css 
- **Backend:** Express.js   
- **Database:** MySQL
